# Ритм игры

Информационный рейтинг игровых платформ

## Требования

- [Bun](https://bun.sh/) — рекомендуется, так как в проекте используется `bun.lockb`.
- Node.js 20.9 или новее, если Bun не установлен.

## Установка и запуск

1. Откройте папку проекта в терминале:

   ```bash
   cd путь/к/aicasino
   ```

2. Установите зависимости:

   ```bash
   bun install
   ```

3. Запустите проект в режиме разработки:

   ```bash
   bun run dev
   ```

4. Откройте в браузере [http://localhost:3000](http://localhost:3000).

После изменения файлов Next.js автоматически обновит страницу.

## Запуск через npm

Если используется Node.js вместо Bun:

```bash
npm install
npm run dev
```

Для production:

```bash
npm run build
npm run start
```
## Основные файлы

- `app/page.tsx` — главная страница и контент рейтинга.
- `app/globals.css` — глобальные стили.
- `app/layout.tsx` — корневой layout и метаданные страницы.
- `package.json` — зависимости и команды проекта.
